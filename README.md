# Zvonitel.ru

**Умная видеорулетка**: случайные видеозвонки 1‑на‑1 с подбором собеседника по интересам, целям, языку и фильтрам. Реализовано продуктовое ТЗ: взаимный матчинг, очередь с приоритетами, модерация и страйки, жалобы, блокировки, приватные комнаты, геймификация, рефералы, админ‑панель и метрики.

Видео идёт напрямую между браузерами (WebRTC, P2P). Сервер занимается только сигналингом, очередью и модерацией — **видео не записывается и не хранится**.

---

## Быстрый старт

```bash
npm install
npm start            # http://localhost:3000
```

Админка: `http://localhost:3000/admin`, демо‑доступ `admin` / `zvonitel` (меняется через `ADMIN_PASS`).

Данные — SQLite в `./data/zvonitel.db` (создаётся автоматически). Внешние сервисы для старта не нужны.

**Подробная инструкция — [INSTALL.md](INSTALL.md):** требования и подготовка системы, что происходит при первом запуске, как проверить звонок, все переменные окружения, настройка тестов, продакшен (HTTPS + TURN — без них в бою не работает), бэкапы и разбор типичных проблем.

**Отдельно — [INSTALL-FASTPANEL.md](INSTALL-FASTPANEL.md):** пошаговая установка на VPS с уже установленной панелью FastPanel (создание сайта, systemd, SSL, nginx-прокси с WebSocket, coturn).

## Что реализовано

### Матчинг (ТЗ §4.1, §5)
- **Взаимное соответствие**: пара создаётся, только если фильтр A подходит профилю B **и** фильтр B подходит профилю A.
- Критерии с весами: язык (26), цель (22), пол (18), возраст (14), темы (12), стиль (8). Язык/цель/пол/возраст — жёсткие, темы и стиль — мягкие.
- «Строгий матч» (скор ≥ 85 + общая тема) и «Гибкий матч» (скор ≥ 55).
- Приоритет очереди: Premium > кто дольше ждёт > выше рейтинг.
- Запрет повторного матча 30 минут, чёрный список после блокировки/жалобы, отдельная очередь для теневого бана.
- Через 30 секунд ожидания — предложение расширить фильтры с конкретными пунктами.

### Звонок (ТЗ §4.3)
WebRTC 1‑на‑1: mute, камера, смена устройств, качество (авто/низкое/среднее/HD), PiP, полный экран, автпереподключение (`restartIce`), индикатор качества по RTT и потерям пакетов, чат, реакции, таймер, генератор вопросов, кнопка SOS.

Режимы: классика, **свидание вслепую** (видео включается через 3 минуты), **языковой обмен**, только голос, нетворкинг, поддержка.

### Безопасность и модерация (ТЗ §4.4)
- Гейт 18+, правила сообщества, апелляции.
- Жалобы (9 причин) → страйки: варн → бан 1 ч → 24 ч → перманентный; для 18+/насилия — сразу бан.
- Автомодерация: фильтр чата (оскорбления, спам, ссылки, телефоны, @handle), детекция подозрительного кадра на клиенте (на сервер уходит только число, не видео), детекция громкости.
- Блокировки (взаимные и односторонние), антибот: капча и лимиты для гостей.

### Социальное и виральное (ТЗ §4.5–4.7)
Профиль, друзья по взаимному согласию, история, рейтинг 1–5 с тегами, 10 достижений, уровни, 3 ежедневных задания, серии дней, лидерборд, реферальная программа (друг зарегистрировался → Premium на день, 3 звонка → ещё 3 дня + 150 монет), приватные комнаты по ссылке `/r/CODE`, тема дня, карточка результата для шеринга, шаринг в Telegram/VK/WhatsApp.

### V2: живые субтитры и перевод
Субтитры включаются одной кнопкой в звонке: браузер распознаёт вашу речь (Web Speech API) и показывает её текст — у вас под своим видео, у собеседника под вашим. **Наружу уходит только распознанный текст, никогда аудио.** Если браузер не поддерживает распознавание (например, Safari) — интерфейс честно говорит об этом, а не молча ничего не делает.

Перевод субтитров подключается к LibreTranslate-совместимому API через свой эндпоинт `/api/translate` (ключ живёт на сервере и не светится в браузере). Задайте `TRANSLATE_URL` — иначе клиент показывает «перевод не настроен».

### V2: запись — только по взаимному согласию
Запись собирается локально в браузере (`MediaRecorder` из композиции: картинка «собеседник + вы в углу» и микс двух микрофонов) и **не покидает устройство** — файл остаётся у пользователя, сервер не получает ни кадра. Это прямо следует правилу ТЗ §4.4 и принципу «видео не хранится».

Флоу защищён на уровне протокола: инициатор жмёт «Записать» → собеседнику приходит явный запрос → **пока он не нажмёт «Разрешить», `MediaRecorder` не стартует ни у кого**. Индикатор до согласия показывает «Запрос записи…», а не «REC». Отказ прекращает сценарий, повторное нажатие останавливает запись и сохраняет файл. Запись автоматически прекращается вместе со звонком и ограничена 10 минутами.

### Мобильная адаптация
Проверено на iPhone SE, iPhone 12, Pixel 7 и узком Galaxy (360 px): нет горизонтального скролла, тач-цели ≥ 44 px, своё видео не перекрывает управление, меню «Ещё» помещается в экран. Учтены `env(safe-area-inset-*)` для «челки», отдельная раскладка для горизонтальной ориентации и отключение hover-эффектов на тач-устройствах.

Мобильные сценарии — приоритет, а не «уменьшенная версия десктопа»: форма звонка по логину на телефоне раскладывается в столбик, экран входящего вызова занимает экран целиком с крупными кнопками, а навигация сжимается так, что кнопка «Начать» всегда доступна (это был реальный баг: на узких экранах аватар перекрывал её — поймано автотестом).

### Оформление
Тёмная пастельная палитра: глубокая сливовая база вместо чёрного и приглушённые акценты — лаванда, мята, персик, небо, роза. Кнопки и пилюли полностью скруглённые, радиусы карточек увеличены, тени — мягкие и тонированные, фоновые пятна медленно «дышат». Все анимации отключаются по `prefers-reduced-motion`.

### Звонок по логину
Кроме случайного подбора можно позвонить конкретному человеку: набрали его логин — и вы на связи сразу, в обход очереди. Поле есть на экране подготовки к звонку, с поиском по первым символам.

Правила намеренно строгие, потому что адресный звонок — это возможность достать конкретного человека:
- звонить могут только зарегистрированные;
- вызываемый **всегда видит, кто звонит**, и может отказать — без его согласия соединение не начнётся;
- блокировка работает в обе стороны: если кто-то из двоих заблокировал второго, звонок невозможен;
- занятому или офлайн-пользователю дозвониться нельзя (честные сообщения «занят», «не в сети»);
- есть таймаут 30 секунд и отмена вызова;
- звонок расходует квоту **обоих**.

Плюс приватная комната по ссылке `/r/код` для тех, кто не хочет светить логин.

### Квоты и монетизация
| | Звонков | Что ещё |
|---|---|---|
| **Гость** | 1 | Случайный звонок без регистрации, чтобы попробовать |
| **Зарегистрированный** | 100 в месяц | Все фильтры и режимы, история, друзья, звонок по логину, достижения |
| **Premium** | безлимит | + запись с согласия обоих, перевод субтитров, приоритет в очереди, гео-фильтры, HD |

Квоту расходует только **состоявшийся** звонок — тот, где P2P-соединение реально поднялось. Неудачное подключение или мгновенный скип ничего не сжигают: платить человек должен за разговор, а не за попытку.

Гостю квота считается по устройству (`guestId` в localStorage). Зарегистрированному — по календарному месяцу, счётчик живёт в базе и виден в интерфейсе («осталось 99 из 100»). Когда квота кончилась, сервис не ломает кнопку, а объясняет, что произошло, и предлагает следующий шаг: гостю — регистрацию, пользователю — Premium.

Защита стоит на трёх уровнях: при постановке в очередь, при формировании пары матчингом (тот, у кого квоты нет, не «подвешивает» второго — собеседник возвращается в очередь) и непосредственно в `startCall` — без квоты звонок не начнётся ни при каком сценарии.

### Админка `/admin`
13 метрик (DAU, средняя длительность, skip‑rate, жалобы на 1000 звонков, виральный K…), очередь жалоб с действиями, живая очередь и активные звонки, пользователи с банами и выдачей Premium, включение демо‑ботов.

### Демо-боты (защита от «пустого сервиса»)
Главный риск молодой рулетки — новичок заходит, ждёт 40 секунд, никого нет и уходит навсегда. Поэтому есть пул демо‑ботов: если живых собеседников нет, через 12 секунд ожидания предлагается «Позвать демо‑бота».

Бот — это настоящий headless‑браузер (`server/bots.js` + `public/bot.js`), который держит обычную Socket.IO‑сессию и настоящий `RTCPeerConnection` с canvas‑видео. То есть тракт звонка ровно тот же, что с человеком: работает бот — работает и человек. Никакого обмана: ник «Демо‑бот Алиса», и бот первой же фразой в чате говорит, что он бот.

Включается в админке (кнопка «Запустить бота») или `POST /api/admin/bots {"on":true,"count":2}`. Если `playwright` не установлен, фича просто отключается, остальной сервис работает.

## Архитектура

```
Браузер A  ─┐                      ┌─ Браузер B
            │  Socket.IO (сигналинг)│
            ▼                       ▼
        Node.js + Express ──── SQLite (пользователи, звонки, жалобы, баны)
            │
            └── MatchingEngine (очередь + взаимный скор)
            └── RoomManager   (приватные комнаты, реестр звонков)
            └── automod       (чат-фильтр, страйки)

Браузер A ◄══════ WebRTC P2P (аудио/видео, через TURN при NAT) ══════► Браузер B
```

| Слой | Файлы |
|---|---|
| HTTP + REST + статика | `server/index.js` |
| Сигналинг, очередь, звонок, модерация | `server/socket-server.js` |
| Алгоритм взаимного матчинга | `server/matching.js` |
| Словари, веса, лимиты, тайминги | `server/config.js` |
| Достижения, задания, рефералы, вопросы | `server/gamify.js` |
| Автомодерация и страйки | `server/automod.js` |
| Комнаты и реестр звонков | `server/rooms.js` |
| SQLite-слой | `server/db.js` |
| UI (SPA без сборки) | `public/js/app.js`, `public/css/app.css` |
| WebRTC-клиент | `public/js/webrtc.js` |
| Камера/микрофон, blur, демо-поток | `public/js/media.js` |

Фронтенд намеренно без сборщика: один HTML + 4 JS‑файла, ничего не нужно компилировать.

Для продакшена обязательно свой TURN:

```bash
ICE_SERVERS='[
  {"urls":"stun:stun.zvonitel.ru:3478"},
  {"urls":["turn:turn.zvonitel.ru:3478?transport=udp","turn:turn.zvonitel.ru:3478?transport=tcp"],
   "username":"zvonitel","credential":"СЕКРЕТ"}
]'
```

## Продакшен

```bash
docker compose up -d       # nginx + coturn + приложение
```

- `docker-compose.yml` поднимает приложение, nginx (TLS, WebSocket) и coturn (TURN/STUN).
- `deploy/nginx.conf` — HTTPS, проксирование `/socket.io/`, заголовки безопасности, gzip.
- Для VPS с FastPanel вместо Docker — отдельная инструкция [INSTALL-FASTPANEL.md](INSTALL-FASTPANEL.md).
- Для масштаба: Redis вместо in‑memory очереди (`MatchingEngine` изолирован в одном классе), PostgreSQL вместо SQLite (схема в `server/db.js` переносится почти 1:1), отдельный TURN‑пул.

## Приватность

- Видео и аудио идут P2P, на сервере не сохраняются.
- В БД лежат только метаданные: длительность, причина завершения, оценки, жалобы.
- Запись звонка — только с согласия обоих участников (в планах V2).
- Гость может звонить без регистрации; данные гостя не привязываются к аккаунту.

## Дорожная карта

- **V1 (сделано):** профиль, рейтинг, друзья, достижения, рефералы, комнаты, админка, метрики.
- **V2 (сделано):** живые субтитры, перевод субтитров, запись по взаимному согласию, мобильная адаптация, обновлённый дизайн.
- **V2 (дальше):** маски и виртуальные фоны (MediaPipe), Telegram‑бот, тематические вечера по расписанию, платежи за Premium, A/B‑тесты в админке.

## Известные ограничения MVP

- Авторизация по токену в `localStorage` (в проде — httpOnly‑cookie + bcrypt + rate limit).
- Очередь живёт в памяти процесса: при горизонтальном масштабировании нужен Redis‑адаптер.
- NSFW‑детекция — эвристика по доле «кожных» пикселей, а не ML‑модель.
- Платежи не подключены: Premium покупается за внутриигровые монеты.
